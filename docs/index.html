How to open an activity

  1. Choose an activity marked Access code required.
  2. Enter the code your instructor gives you for that activity.
  3. Complete the activity in your browser. If it offers a report download, save your report before closing the page.

You do not need an account. Opening this site does not record anything or send your work to the instructor.

Each activity needs its own access code, provided by your instructor.
